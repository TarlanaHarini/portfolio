## Installation

1. Clone the repository:

```bash
git clone https://github.com/TarlanaHarini/your-repository-name.git
```

2. Navigate to the project directory:

```bash
cd your-repository-name
```

3. Install dependencies:

```bash
npm install
```

4. Start the application:

```bash
npm start
```

5. Open:

```text
http://localhost:3000
```
